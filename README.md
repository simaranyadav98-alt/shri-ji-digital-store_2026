# Shri Ji Digital Store — Website Launch Package

## Included
- Responsive storefront home page
- About, Products and Contact pages
- Privacy, Terms and Refund policy starter pages
- 404 page, robots.txt, sitemap.xml, manifest.json and favicon
- Basic SEO and social-sharing metadata

## Before publishing — important
1. Replace `https://YOUR-DOMAIN.example/` in `index.html`, `robots.txt` and `sitemap.xml` with your actual live website URL.
2. Replace `YOUR-EMAIL@example.com` and the WhatsApp placeholder in `contact.html`.
3. Add your real products, accurate prices, product images and secure checkout/download links. Sample product cards are not connected to payment.
4. Review and customize the legal policy pages to match your real business, payment provider, data collection and applicable laws. These are starter templates, not legal advice.
5. Add a real social preview image at `assets/social-preview.png` (1200×630 recommended) or update the `og:image` URL.
6. Test every page and link on a mobile phone before sharing publicly.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository for the store.
3. Upload the contents of this folder to the repository's root (not the ZIP file itself). `index.html` must be at the root.
4. Commit the uploaded files.
5. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → select `main` and `/ (root)` → Save.
6. Wait for GitHub Pages to publish, then open the URL shown in Settings → Pages.

## Google search visibility
After the site is live:
1. Open Google Search Console and add your exact site URL.
2. Complete ownership verification.
3. Submit `https://YOUR-DOMAIN.example/sitemap.xml` after replacing the placeholder domain.
4. Use URL Inspection to request indexing of the home page.

Indexing is not instant or guaranteed. Google decides when and whether pages appear in search results.

## Notes
- This is a static website. It does not include a database, customer login, order management, automated file delivery or payment processing.
- Do not collect sensitive payment information directly on this site. Use a trusted checkout provider.
